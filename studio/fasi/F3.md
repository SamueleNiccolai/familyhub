- Rispondere alle domande base su JavaScript e TypeScript (closure, event loop, `this`, narrowing) con esempi miei.

## Definition of done
- 2 tab navigabili + dettaglio; client API tipizzato (`npx tsc --noEmit` esce con 0, con `"strict": true`); `EXPO_PUBLIC_API_URL` punta alla produzione.
- Spuntare una voce è istantaneo anche con rete lenta (prova con throttling o modalità aereo → rollback visibile).
- `npm test` verde in locale e in CI; flow Maestro che passa in locale (video o screenshot in evidenze), se non è stato tagliato.

## Trappole e punti di scoraggiamento
- Voler «sapere tutto React» prima di toccare l'app: 30 minuti di lettura, poi codice.
- `useEffect` per il fetch: in F0 l'ho fatto apposta, da qui si usa Query. Ai colloqui chiedono entrambe le cose: cosa non va nel fetch con `useEffect` (race, cleanup, cache) e cosa risolve Query.
- Ore perse sullo styling: funziona prima, bello dopo.
- Errori criptici del toolchain RN: quasi sempre versioni → `npx expo install --fix`, cancellare `node_modules`, riprovare.
- Expo Go (e l'APK di anteprima per i familiari Android) bastano fino a F6; niente dev build ora.
